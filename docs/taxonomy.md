# Historical atlas taxonomy

`data/curated/atlas_taxonomy.csv` maps each original atlas entry to an Avibase taxon concept, using a more precise Kenyan AviList species where the Kenya checklist and available comparison membership support one. It contains 1,067 rows: original numbered SEQs 1–1065 and two newly assigned codes, `0a` (Shoebill) and `0b` (Taita Thrush). These two taxa had SEQ 0 in the original digitized workbook; the new codes are project identifiers, not numbers printed in the book. SEQ must be read as text.

The initial mapping matched historical scientific names to AviList v2025b, with modern names from the comparison project used as aliases where needed. Difficult cases were checked against selected book scans, Avibase concept pages and eBird taxonomy v2025.4. The `source`, `atlas_page` and `notes` fields record the evidence and limitations. A name match is provisional: historical taxon boundaries have not been individually verified for every row. `kenyan_match` identifies 51 more precise Kenyan species selected using the Birds-of-Kenya v2026.0 checklist, its 2019-to-2026 mapping, and comparison membership; earlier broader IDs and uncertainty are retained in each row’s notes. These matches are provisional rather than independent expert validation. `parent_fallback` means the selected concept is broader or its exact scope is uncertain; do not automatically expand that parent into all modern species. The two lovebirds retain nominal species IDs, with notes about feral and hybrid birds in the book.

The atlas workbook records four scientific-name transcription corrections in separate Git commits. The original workbook remains available through Git history. The book's SEQ 26 is Little Bittern and 27 Dwarf Bittern; the old GBIF lookup, now removed, had them reversed.

The same table records Catalogue of Life IDs in `col_id`, the reference name in `col_name`, the decision or review status in `col_status`, an explanation in `col_notes`, and whether to use the ID in occurrences in `col_publish`. `name_matched` entries are unverified automatic exact matches, not expert-reviewed concepts. `species_review`, `broader_species_review` and `rank_review` retain the reason to review; selected broader species can overlap another atlas entry. `broader_genus` entries are genus-level parents. They are deliberately broader than the atlas concept and can overlap other SEQs or cause GBIF to interpret a record at genus level.

`scripts/05_match_catalogue_of_life.m` is an optional research tool that queries GBIF's Catalogue of Life Extended Release and writes proposals to `data/intermediate/atlas_col_name_matches.csv`. It never overwrites the curated decisions. Catalogue of Life identifications were checked against the API on 31 October 2026; the matched usage can be a synonym and the accepted name or rank can differ.

`06_prepare_occurrence` creates the occurrence CSV. It uses the Avibase scientific name where available, and records the original atlas scientific and common names in `verbatimIdentification` and `vernacularName`. The atlas scientific name is also included in `identificationRemarks`, because some publishing mappings do not support `verbatimIdentification`. For group labels without one unambiguous name it retains the historical atlas name and adds an identification remark. The Avibase ID records the selected concept; the name may represent a narrower GBIF match. GBIF diagnostics are not used to select occurrence identifications. The Avibase ID is retained in `taxonID`, including documented broader parent fallbacks. `taxonConceptID` carries `col_id` when `col_publish` is true; the scope and uncertainty in `col_notes` are carried in `identificationRemarks`. All 1,067 curated rows now have a COL ID; the original SEQ is in `identificationRemarks`. Numbered occurrence IDs are unchanged. The one original SEQ 0 occurrence is the source Shoebill record; it retains its published occurrence ID for continuity, although its taxon SEQ is now 0a. The earlier export mislabeled it as Taita Thrush. No Taita Thrush occurrence is present in the current source periods.

`04_taxonomy_reference` joins the supplied AviList v2026 workbook to the curated IDs. For IDs absent from AviList 2026 it checks the Avibase 2025 bibliographic sheets, in their listed order, and records the source authority. The original files are in `data/raw/taxonomy/`. The generated table contains order, family, rank and authorship where available: AviList matches 1,019 IDs; the bibliographic file supplies four additional IDs. Another 44 are absent from both exact-ID matches. For group concepts, rank and authorship are left blank rather than treating a constituent species as the entire group. The occurrence export retains the atlas names and Avibase identifiers.

A GBIF validator run reported the former local `atlas-seq:` taxon IDs and Avibase concept links as not found. The export now uses the Avibase ID as `taxonID`. GBIF currently does not list Avibase among the identifiers it resolves, so a taxon-ID lookup warning may remain. Do not infer that an Avibase concept is invalid from this warning.

Validator counts are per occurrence, not per species. Its 177 higher-rank and 150 fuzzy occurrence flags should be investigated using the validator interpreted or issue-level results; the separate API diagnostic uses a specified taxonomy and its counts are not directly comparable. The `country derived from coordinates` and `continent derived from coordinates` messages report GBIF enrichment. Atlas locations are quarter-degree square centres, including border or coastal squares, so do not assign country or continent to every record without checking their geographic scope.

See [taxonomic decisions needing qualification](taxonomy_decisions.md) for the atlas entries whose Avibase or Catalogue of Life matches are broader, manually selected or otherwise flagged. The CSV is the authoritative per-taxon record. GBIF may prefer an identifier-based match to the supplied scientific name, so a genus-level COL parent can change its interpreted rank or cause a name-and-ID ambiguity flag.

The comparison project reads `export/comparison/atlas_records.csv` directly. `scripts/04_taxonomy_reference.m` also exports the pinned AviList v2026 subset as `export/comparison/avilist_taxa.csv`, supplying one reference for comparison names and website links. Comparison merges or identification exclusions live in KenyaAtlasComparison's curated `atlas_mapping.csv`; they do not replace these historical IDs.

The 2026 coherence review corrected the lark groups using printed pp. 306–307 (scan files 323–324): SEQ 531 retains the former africana complex, including current Athi Lark, and SEQ 532 retains hypermetra/kidepoensis, including the book's Ugandan records. Their earlier single-species IDs were too narrow. Existing narrower COL species IDs are retained for review with `col_publish=false`, so they are not emitted as equivalent occurrence concept IDs. Spotted Flycatcher retains its pre-2026 striata/tyrrhenica concept; the comparison lists both current members and does not redefine unidentified old records as the narrower new species.
